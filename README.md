# Teologi Rekonsiliasi - Artikel Interaktif

Repository ini berisi halaman web interaktif yang menyajikan artikel mendalam tentang **Teologi Rekonsiliasi (Theology of Reconciliation)**. Halaman web ini dirancang dengan gaya modern, estetika premium, responsif, dan interaktif.

## Fitur Halaman Utama

1. **Artikel Teologis Komprehensif:** Mengulas teologi rekonsiliasi secara mendalam: Pendahuluan, Sejarah & Perkembangan (era Gereja Mula-mula, Reformasi, hingga WCC), Tiga Dimensi Utama (Vertikal, Horizontal, Ekologis), Tokoh Kontemporer, Landasan Alkitab, dan Aplikasi Kontekstual di Indonesia.
2. **Kajian Tokoh Kontemporer:** Menyediakan kartu interaktif yang menjelaskan kontribusi teologis Miroslav Volf (*Exclusion and Embrace*) dan Desmond Tutu (*Ubuntu & Restorative Justice*).
3. **Landasan Alkitab & Data Komparasi:** Menyajikan ayat-ayat alkitab kunci (Matius 5:9, Kolose 1:20, Roma 12:18, Kejadian 50:20) serta tabel perbandingan interaktif antara paradigma Keadilan Retributif vs Restoratif.
4. **Peralihan Tema (Light/Dark Mode):** Desain adaptif dengan transisi mulus dan penyimpanan preferensi pengguna di peramban (*localStorage*).
5. **Indikator Kemajuan Membaca:** *Scroll progress bar* di bagian atas halaman untuk mengetahui posisi membaca saat ini.
6. **Daftar Isi Melayang (Floating TOC):** Navigasi dinamis yang menyorot bab artikel yang sedang dibaca saat digulir (mendukung 9 bab utama).
7. **Jurnal Refleksi Interaktif:** Fitur refleksi pribadi dengan penyimpanan otomatis secara lokal (*localStorage*) agar tulisan Anda tidak hilang saat memuat ulang halaman.

## Struktur Berkas

- `index.html`: Struktur HTML semantic dan kode pemrograman logika interaktivitas JavaScript.
- `style.css`: Lembar gaya (stylesheet) vanilla CSS yang mengimplementasikan sistem desain, variabel warna, transisi, dan responsivitas layout.

## Cara Menjalankan

1. Kloning repository ini atau unduh berkasnya.
2. Klik ganda pada berkas `index.html` untuk membukanya secara langsung di peramban web pilihan Anda (Google Chrome, Firefox, Edge, Safari, dll.).
3. Tidak diperlukan instalasi pustaka eksternal atau server web lokal untuk membuka halaman ini.
